КАК ОБНОВИТЬ САЙТ

Скопируй ВСЁ содержимое этой папки в свою папку portfolio на Маке.
Замени прежний index.html. Дополнительно нужны content.js, app.js и style.css.
Открывай index.html двойным кликом: сервер и установка программ не нужны.
Это локальные файлы. На GitHub ничего автоматически не отправляется.

ЧТО РЕДАКТИРОВАТЬ
content.js — тексты, проекты, порядок, категории и пути к материалам.
assets — твои картинки и видео.
app.js и style.css — механика и оформление, для обычного обновления их трогать не нужно.
Тексты перенесены из первоначального макета; их редактуру ещё обсуждаем отдельно.

ПЕРВЫЕ ОБЛОЖКИ
Брешь: assets/bresh/cover.jpg
RCD: assets/rcd/cover.jpg
Положи сюда свои файлы. Пока файлов нет, остаются цветные заглушки.
Рекомендация: JPG или WebP, 1600×900 (16:9). PNG тоже работает.
Если расширение другое, измени cover.src в content.js: например cover.webp.
Имена файлов и регистр букв должны совпадать полностью.
На сайте все обложки 16:9. cover.fit: "cover" обрезает края.
cover.position: "50% 50%" — центр; "50% 20%" — сдвиг к верхней части.
cover.fit: "contain" — вся картинка целиком с полями цвета cover.background.
Капсулу Steam можно использовать, но сначала проверь обрезку текста и важных деталей.

ПОРЯДОК И КАТЕГОРИИ
Порядок объектов внутри projects — порядок карточек. Просто переставляй объекты.
Название папки не связано с номером: при перестановке переименовывать папки не нужно.
В categories можно добавлять категории. Счётчики и кнопки создаются автоматически.
У одного проекта может быть несколько категорий: "categories": ["games", "video"].
visible: false скрывает проект из списка и убирает его страницу.

ДОБАВЛЕНИЕ ПРОЕКТА
Скопируй целиком объект проекта внутри projects и вставь на нужное место.
Между объектами нужна запятая. У каждого проекта должен быть уникальный id:
латинские буквы, цифры, дефисы; например street-redesign.
Не используй id all, home, works, about, projects, project-pages, intro-title.
id определяет ссылку (#street-redesign), поэтому после публикации лучше его не менять.
Папку можно назвать как угодно: assets/street-redesign или assets/project-03.
Укажи title, summary, categories, cover.src. tag и eyebrow — короткие подписи.
Страница проекта создаётся автоматически, даже если "blocks": [].
Весь сайт переделывать для нового проекта не требуется.

БЛОКИ СТРАНИЦЫ ПРОЕКТА
Порядок внутри blocks — порядок блоков. Ненужные блоки можно убрать.
Обычный текст:
{ "type": "text", "title": "Задача", "paragraphs": ["Первый абзац", "Второй абзац"], "bullets": ["Пункт"], "notes": ["Подпись"], "links": [{"label": "Открыть", "url": "https://example.com"}] }
Картинка:
{ "type": "image", "src": "assets/project-03/01.jpg", "alt": "Что изображено", "caption": "Подпись" }
Галерея:
{ "type": "gallery", "images": [{"src": "assets/project-03/01.jpg", "alt": "Описание", "caption": "Подпись"}] }
Сравнение с ползунком (одинаковые размеры изображений и точка съёмки):
{ "type": "comparison", "title": "До и после", "before": "assets/project-03/before.jpg", "after": "assets/project-03/after.jpg", "beforeLabel": "ДО", "afterLabel": "ПОСЛЕ", "caption": "Подпись" }
Локальное видео с кнопками управления:
{ "type": "video", "src": "assets/project-03/video.mp4", "poster": "assets/project-03/poster.jpg" }
Особенный интерактивный блок можно добавить отдельно; существующие проекты от этого не меняются.

Размеры: обложки 1600×900 px; остальные изображения — 1600–2000 px по длинной стороне.
Обычно достаточно 200–600 КБ на JPG, если не теряются важные детали.
Личные материалы: assets/about; логотип: assets/branding; памятник: assets/memorial.

Если правки не видны, сохрани content.js и обнови страницу.
После проверки локально: commit и push через GitHub Desktop, когда захочешь отправить изменения.
